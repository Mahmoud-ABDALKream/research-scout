# Build-in-public — Research Scout

*LinkedIn / FlyRank showcase. ~250 words. One real decision, one real limitation.*

---

I built **Research Scout**: a personal agent that pre-qualifies React / product roles for me (healthcare, e-commerce, junior-friendly, Egypt or remote) so I stop doom-scrolling Wuzzuf and LinkedIn. Five steps — gather, read, score, filter, format. The live UI is on my site at `/scout`. I still click Apply.

**One decision I’d make again: the agent is not allowed to apply.**

The impressive demo is auto-submit. That’s also how you spam twenty listings with a hallucinated pitch. Ranking is the job. The seniority penalty is the same family of decision: on the first run a Senior Front-End role scored 5/9 because the stack matched. I’m a student. Four mechanical signals now pull that score down (cap −4). The eval is 6/6. I would rather a quiet digest than a confident wrong one.

**One limitation I’m honest about: boards that block the reader.**

LinkedIn and Upwork often return Cloudflare or a login wall. Those URLs get a low-signal flag or a zero. I don’t invent a job description I couldn’t read. The cost is coverage — especially freelance gigs. Next I’d lean on official APIs and RSS, not a stealth scraper.
